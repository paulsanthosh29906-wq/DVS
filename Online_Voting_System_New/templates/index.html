About

This academic Online Voting System uses HTML, CSS, JavaScript, Python Flask and MySQL. Voter IDs are generated as unique alphanumeric values, each voter can vote once per election round, voting time is controlled by the administrator, and election results are restricted to the Admin Dashboard.
